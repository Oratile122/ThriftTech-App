# Thrift Tech Mobile App

## Project Description
A fully functional Android marketplace for buying and selling second-hand clothing, built for Thrift Tech in Braamfontein. The app features secure authentication, image uploads, and real-time database syncing.

## Development Overview
The app was built using Kotlin and Jetpack Compose. We used Firebase Authentication for secure login and Google SSO, Firebase Firestore for the database, and the Cloudinary API for image hosting. We utilized GitHub Actions for automated build and testing.

## Release Notes - Version 1.0 (Final Release)
Since the initial prototype, the following innovative features were added to the app:
*   **Google Single Sign-On (SSO):** Users can now log in instantly using their Google account.
*   **Cloudinary API Image Uploads:** Users can upload real photos from their phone gallery when selling an item.
*   **Advanced Marketplace Search:** Added a real-time search bar and category filter chips.
*   **Profile Management:** Users can now update their name and phone number.
*   **Secure Delete Feature:** Users can only delete items they posted themselves.
